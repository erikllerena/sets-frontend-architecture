# ADRs — Frontend Architecture

Documenta decisiones reales de arquitectura frontend usando `sets-framework/templates/ADR_TEMPLATE.md` cuando un ADR ayude a conservar contexto, alternativas, consecuencias y condiciones de revisión.

No generes ADR por rutina para cada concepto. Las decisiones entre capas deben dejar claro qué parte pertenece al frontend y qué parte corresponde a contratos de API/BFF, plataforma o arquitectura integral. No dupliques artefactos de otros programas: enlaza cuando corresponda.


Esta guía trata ADRs **técnicos** sobre soluciones y diseños; no es `DECISION_ENGINE.md` (razonamiento pedagógico), ni una guía de decisiones administrativas del programa. Se incorpora como fuente solo cuando el trabajo con ADRs lo justifique.
