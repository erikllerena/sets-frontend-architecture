# Labs — Frontend Architecture

Guardar ejercicios, diagramas, experimentos y pruebas **realmente realizados**. Un laboratorio conceptual puede ser un modelo causal, una tabla de estados, un threat model o una decisión argumentada; no todo requiere código.

Para experimentos de performance, accesibilidad, rendering o compatibilidad, anota entorno, condiciones, método y resultados observados. No inventes métricas, resultados de navegador, profiler, auditoría, tests o despliegues. Distingue resultados medidos de hipótesis y planes de verificación.
