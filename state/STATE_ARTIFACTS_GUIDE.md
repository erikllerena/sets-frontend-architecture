# Estado del programa

`LEARNING_STATE.md` sintetiza el progreso actual y `EVIDENCE_LOG.md` conserva las observaciones reales de forma acumulativa. No reemplaces un historial con evidencias por una plantilla vacía.

`CONCEPT_MAP.md` es opcional: organiza relaciones conceptuales, pero no califica ni demuestra dominio. `LAST_HANDOFF.md` no viene precreado; se genera después de la primera sesión real mediante `/close`, usando `sets-framework/templates/LAST_HANDOFF.template.md` y `core/SESSION_HANDOFF.md`.

Flujo normal: `/close` → revisar los artefactos propuestos → guardar en GitHub → actualizar fuentes del Proyecto de ChatGPT → abrir otra conversación dentro del mismo Proyecto y usar `/resume`. No hay sincronización automática por defecto.

## Inicio limpio

Los archivos de esta versión comienzan sin progreso evaluado. Cada Proyecto de ChatGPT mantiene sus propias sesiones, evidencias y continuidad. Si en el futuro el repositorio contiene datos reales, respáldalos y revisa las diferencias antes de reemplazar archivos.


Este archivo se llama `STATE_ARTIFACTS_GUIDE.md` para identificarlo de forma inequívoca al subirlo individualmente como fuente de ChatGPT.
